# Playtest Feedback

Use this for the 5-20 tester external release candidate.

## In-Game Feedback Path

- Use Help -> Save before reporting a bug.
- If Dev Overlay is enabled for the tester build, use the telemetry export control and attach the exported debug JSON.
- If no form link is configured for the build, collect reports with the bug template below.

## Post-Play Survey

1. Did you understand movement and camera controls within the first minute?
2. Could you identify what item or spell was equipped?
3. Could you assign and use a hotbar slot?
4. Could you gather a resource without outside help?
5. Could you cast a spell and understand invalid spell feedback?
6. Could you fight an enemy and heal afterward?
7. Could you follow the current objective?
8. Could you complete one work order or quest?
9. Did saving and resuming preserve your state?
10. What was the first moment where you felt stuck or confused?
